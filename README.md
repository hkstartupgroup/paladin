# 仙劍奇俠傳 · 終端文字版

純文字（Terminal）仙俠 RPG，以「升級練武」與「劇情體驗」為核心。改編自經典《仙劍奇俠傳一》，
以回合制戰鬥、武學成長與章節式劇情推進，重現餘杭小鎮、仙靈島、蘇州、蜀山、苗疆的江湖旅程。

> 目前進度：**第一章「仙島求藥」全篇完成**（盛漁村序幕 → 仙靈島 → 回村失憶 → 十里坡山神廟習御劍術），並加入盛漁村渡口市集商店買賣與客棧投宿休息。對應藍圖階段 1、1.5～1.9、6、7。

## 遊戲特色

- **回合制戰鬥**：攻擊 / 武功 / 物品 / 逃跑，身法決定出手順序，含會心一擊與隨機掉落。
- **升級成長**：經驗、等級、屬性自動成長，並隨等級習得新武功（learnset）。
- **武學系統**：李逍遙（御劍術、天師符法、萬劍訣 Lv13、天劍 Lv23、逍遙神劍、劍神、酒神、山神、雷神、氣療術、凝神歸元、冰心訣、天罡戰氣、真元護體、醉仙望月步、仙風雲體術、元靈歸心術、飛龍探雲手、靈葫咒、金蟬脫殼）與趙靈兒（五系咒法、觀音咒、淨衣咒、金剛咒、回夢、還魂咒、五氣朝元、三昧真火、武神…）依原作補齊；御劍術由酒劍仙劇情傳授、氣療術為自帶。
- **戰鬥機制**：除攻擊／治療外，支援**異常狀態**（中毒、昏睡、定身、瘋魔、咒封）、**增益**（攻擊／防禦／身法）、**復活**、**解咒**、**偷竊**與**脫逃**；中毒每回合扣血、昏睡／定身無法行動、瘋魔不分敵我、咒封禁用仙術，身受擊會驚醒。
- **擋格彩蛋**：敵方普通攻擊隊友時，李逍遙會挺身替**女角**擋下這一擊（唯獨不替林月如），林月如則只替李逍遙擋格（她日後入隊才生效）；擋格成功時由擋格者代受半數傷害。此為玩家間流傳的戲說、非原作明載，因頗合人物性格而實作。
- **劇情引擎**：節點式劇情、對話演出、抉擇分歧、戰鬥觸發、獎勵發放、劇情傳授技能。
- **場景探索**：以「移動／探索」在場景間走動；找對人物對話或物件互動才會推進劇情（點選式 ADV）。
- **當前目標**：狀態列依主線旗標顯示下一步該做什麼（例如「到渡口市集，替嬸嬸買幾斤新鮮的蝦」），全章完成後顯示收尾提示。
- **隱藏寶物**：依原著攻略在各場景布置可調查的寶物（皮帽、木鞋、梅花鏢、蠱卵、蓮蓬等），取走後即不再出現。
- **夥伴參戰**：趙靈兒自客棧獲救起加入隊伍（等級比照李逍遙），入隊時自帶仙女劍（武術+8／防禦+5）、布袍（防禦+3）、青絲巾（防禦+2）、草鞋（防禦+1）；房間戰與拜月教頭領戰皆與李逍遙並肩作戰，戰鬥與「隊伍狀態」操作同李逍遙。**靈兒在隊時，仙靈島岩徑的綠葉小妖／綠葉妖精會自動退避**（見「原著忠實度」）。
- **裝備系統**：武器／防具／頭部／足部／飾品五部位，於「隊伍狀態」換裝；裝備即時加成屬性，卸下即還原。各裝備依原作的「裝備角色」設有對象限制（`Item.equipBy`，如繡花鞋／髮飾／玉鐲限女角、仙女劍限趙靈兒、生鏽鐵劍限李逍遙），換裝清單僅列出該角色能穿戴的品項。
- **商店買賣**：盛漁村渡口市集的鐵匠鋪（曾大伯）、木匠鋪（林木匠）與洪大夫藥鋪可買賣兵器、防具與藥品；售價依原作，出售比照當鋪以原價 75% 收購。
- **客棧投宿**：於客棧的床榻休息可回滿全隊生命與真氣；餘杭客棧因是自己的家，於李逍遙房休息免費，他處客棧則需付投宿費（`restCost`）。
- **探索練功**：在十里坡、仙靈島岩徑等野外「四下探索」，隨機遇上**遇敵／寶箱／空手**，可無限練功兼尋寶（**不做迷宮**）。十里坡在仙靈島歸來前封閉，詳見「原著忠實度」。
- **存讀檔**：純 JSON 存檔，資料結構向下相容於後續階段。

## 原著忠實度

主線依《仙劍奇俠傳一》推進，**台詞逐字採用《新仙劍奇俠傳》劇情對話原文**，流程與設定以原著攻略為準：

- 李逍遙開場自帶**氣療術**（原作設定），但不會御劍術；仙靈島上沒有強力劍招，御劍術要到山神廟才習得。
- **御劍術是在自仙靈島歸來、忘憂散發作失憶之後**，夜赴十里坡山神廟，由酒劍仙傳授——既非序章習得，也非升級習得。
- **去仙靈島前十里坡封閉**：渡口市集往十里坡的山徑於仙靈島歸來前不通（旗標 `island.returned`）；移動選單仍會顯示該出口，選取時以提示文字表示封閉，仙靈島歸來後開啟。
- **場景角色隨劇情進退場**：NPC 依旗標分階段出現，同一角色不會同時出現兩筆。例如嬸嬸病倒（`aunt.sick`）後李大娘離開大廳、廚房；市集村民改口關心，丁香蘭通報後離去；取得破天鎚（`sail`）後市集只留張四哥可出航。苗人頭領自收到賞銀起在大廳持續可互動，得知仙靈島（`go.island`）後改為贈送破天鎚；二樓苗人嘍囉端完酒菜後仍留在房內；李大娘房中的人物亦可重複對話。
- **第一章流程（盛漁村段）**：餘杭客棧招呼苗人（賞 500 文）→ 奉嬸嬸之命趕醉道士 → 送酒菜、桂花酒轉贈醉道士 → 醉道士約三更十里坡山神廟 → 嬸嬸令買蝦（渡口市集）→ 丁香蘭通報嬸嬸病倒 → 洪大夫束手、王小虎指路 → 苗人頭領贈破天鎚與忘憂散 → 張四哥載往仙靈島。
- **第一章流程（仙靈島至御劍術）**：張四哥載至岸邊 → 岩徑（遭遇綠葉小妖／綠葉妖精）→ 荷花池以破天鎚敲碎六具阿修羅石像破陣 → 桃樹林 → 水月宮外遇趙靈兒（草叢可拾苗刀，為阿奴寶物）→ 水月宮取紫金丹、姥姥逼婚、連夜逃出 → 張四哥載回盛漁村 → 李大娘服紫金丹痊癒、李逍遙昏厥失憶 → 夜赴十里坡山神廟，酒劍仙傳授御劍術。
- **第一章流程（後半段至完結）**：回客棧聽嬸嬸交代（房間被苗人佔用、房門有守衛）→ **走廊房門封閉，須從柴房爬繩索走密道溜回自己房間** → 逍遙房中發現被捆的趙靈兒，擊退苗人嘍囉 → 靈兒哭求回仙靈島救姥姥 → 張四哥再度載往 → 水月宮已成血海、姥姥臨終將靈兒託付逍遙 → 回盛漁村、客棧遭拜月教圍攻 → **客棧之戰：苗人頭領與兩名苗人嘍囉** → 李大娘出手（穿雲掌）解圍 → 靈兒留宿、隔日嬸嬸允其同赴苗疆 → 渡口搭方老闆便船啟程（**第一章完**）。
- 餘杭客棧各處依攻略藏有隱藏寶物，已落為可調查物件：逍遙房花架皮帽、書櫥木鞋；二樓客房梅花鏢；第一間客房花盆蠱卵；走廊花盆 15 文；嬸嬸房櫃子 50 文、桌上水果；櫃台 200 文、櫃台旁酒罈雄黃酒；廚房蒸籠糯米糕、櫥櫃鹽巴、罈子水果、灶邊燒肉；柴房茶葉蛋。
- **暗器**：梅花鏢為一次性投擲道具（戰鬥中「物品」投擲單體、造成固定傷害），並非裝備；戰鬥外不可使用。
- **苗刀為寶物**：水月宮外箱底的那把苗刀，原作是**阿奴專用**的後期武器（武術+70／身法+32），李逍遙無法裝備；本作比照處理，列為不可裝備的貴重品（售價 5000，可於商店變賣 3750 文），以免第一章即取得壓倒性戰力。
- **商店依原作**：盛漁村渡口市集的鐵匠鋪（曾大伯）賣短刀／護肩／披風／鐵履／護腕／鐵護腕，木匠鋪（林木匠）賣木劍／藤甲／木鞋／草鞋／皮帽／髮飾，洪大夫藥鋪賣止血草／還神丹／還魂香；裝備加成與售價皆採原作（木劍武術+2／身法+3＝50 文、短刀武術+6／身法-5＝200 文、藤甲防禦+7＝400 文、鐵履防禦+6＝1100 文等）。出售比照原作當鋪，以原價 75% 收購。
- **敵人數值依原作**：十里坡與仙靈島敵人依《新仙劍》敵人列表校準──HP 採原作原值，武術約為原作的 1/3、身法約 1/2（配合本作傷害與先後手公式）；綠葉妖精會施展原作招式「風咒」。校正後仙靈島岩徑略高於十里坡中段，於仙靈島歸來開啟十里坡練功後仍具挑戰，商店裝備也才真正派上用場。
- **靈兒在隊時仙靈島小妖退避**：趙靈兒在隊伍中時，仙靈島岩徑的綠葉小妖／綠葉妖精會認出少宮主而自動一哄而散、不進入戰鬥（小妖本為水月宮座下）。因此靈兒入隊後，仙靈島岩徑不再是練功點，練等請改往十里坡。
- **客棧拜月教之戰**：原作攻略為「**三名苗人圍攻（苗人拳、胖苗人）**」，打完之後**苗人首領才現身**、被李大娘一掌穿雲掌打死（首領本不入戰鬥）。本作改編為**苗人頭領＋兩名苗人嘍囉**（頭領親自出戰），並上調苗人嘍囉（HP 90→110）與苗人頭領（HP 200→300、攻擊 26→28、防禦 12→13、身法 14→15）的強度，使首章 Boss 戰名副其實（建議先於十里坡練等）。
- **嬸嬸的包袱依原作**：啟程苗疆前，李大娘交給李逍遙一只**包袱**（於「道具」使用可開啟）：內有 500 文錢、手卷、金創藥×2、還神丹×2、繡花鞋、玉鐲、生鏽鐵劍。其中**手卷**可習得「冰心訣」與「飛龍探雲手」（補上李逍遙原本無取得途徑的兩招，並帶出父母為南盜俠的伏筆）；生鏽鐵劍、繡花鞋、玉鐲皆採原作數值。
- **道具數值依原作**：名稱、功效與數值對齊《新仙劍》（如鼠兒果＝恢復真氣+36、龍涎草+110、雪蓮子+400、觀音符＝體力+150、金創藥＝體力+200、行軍丹＝體力+100；「體力真氣+X」類道具兼補真氣）。原作未收錄的「靈芝草／大金創藥／還魂丹」已更名為還神丹（真氣+50）／蟠果（體力+450）／還魂香（復活並回復 10% 體力）。雄黃酒、鹽巴為解毒類，因本作尚無中毒系統暫列材料。裝備亦採原值（皮帽防禦+4、木鞋防禦+2、短刀武術+6／身法-5 等），並依原作設定「裝備角色」限制（見下條）。
- **裝備對象依原作**：原作各裝備有其可穿戴的角色，本作以 `Item.equipBy`（角色 id 或 `male`／`female`）標記並由 `canEquip` 判定，換裝清單只列該角色可穿者。例如**繡花鞋**限趙靈兒、林月如（李逍遙不可穿）、**仙女劍**限趙靈兒、**生鏽鐵劍**限李逍遙；**髮飾／玉鐲／青絲巾**等飾品限女角；木劍、短刀、披風等限李逍遙、林月如；木鞋、草鞋、鐵履三人通用；藤甲、護肩、布袍、護腕等未特別限制者則不限對象。
- 「五雷咒」為趙靈兒招式，李逍遙的雷系為後期的「雷神」。

**《新仙劍》的「夢境·羅剎洞」序章暫不實作**，本作自餘杭客棧開場。
**第一章台詞全文謄錄自 [docs/story/main/ch01.md](docs/story/main/ch01.md)**，`src/data/chapters/chapter01.ts` 依場景與互動切分為段落（含後半段：趙靈兒被擄、拜月教圍攻、苗人頭領 Boss、李大娘出手、啟程苗疆）。
**尚未納入第一章的原著支線**（皇甫英述父母往事、洪大夫藥舖贈靈山仙芝、丁家姊妹贈布靴等）留待階段 4「客棧風雲」處理。
**趙靈兒角色資料（屬性、初始五系咒法與升級技能）已建立於 `characters.ts`**；自客棧房間獲救起正式入隊（等級比照李逍遙），房間戰（對兩名苗人嘍囉）與後續拜月教頭領戰皆與李逍遙並肩作戰。完整隊伍系統（換人、前排後排、全隊經驗分配）仍待階段 3。
「升級練武」為原作所無的遊戲性外掛：以野外練功點（`練武` 選單，十里坡、仙靈島岩徑）提供自由練等，主線劇情本身不強加戰鬥。

## 快速開始

```bash
npm install
npm start                # 開始遊戲
npm run dev              # 開發模式（熱重載）
npm run dev inn-hall     # 開發模式並直接跳到指定場景
npm test                 # 執行單元測試
npm run build            # 編譯並型別檢查
npm run build:web        # 打包單一 HTML 網頁版（輸出 paladin.html）
```

需求：Node.js >= 20.6

### 網頁版（單一 HTML，免安裝）

若要把遊戲直接分享給不熟終端機的人，可打包成**單一 HTML**：

```bash
npm run build:web        # 產生 paladin.html（約 126 KB，已內嵌全部資料與程式）
```

把產生的 `paladin.html` 單獨傳給對方，用瀏覽器（Safari / Chrome）雙擊開啟即可玩，**不需要安裝 Node.js、不需要終端機，也不會有 macOS 的開發者警告**。進度存在瀏覽器 localStorage（主選單可「存檔」，標題畫面可「讀取存檔」）。

- 網頁版與終端機版**共用 src/ 的遊戲規則與資料**（`src/systems`、`src/data`），避免雙份實作；網頁端僅保留流程與 DOM 呈現。網頁引擎（[web/src/main.ts](web/src/main.ts)）直接 import 這些共用模組，由 [scripts/build-web.ts](scripts/build-web.ts) 以 esbuild 打包 [web/style.css](web/style.css) 產生；改完資料重新執行 `npm run build:web` 即可更新。
- `paladin.html` 為產物，可自由複製分享。

### 部署到 GitHub Pages（線上遊玩）

`paladin.html` 是**單一自帶檔**（CSS／JS／資料全內嵌，無任何外部資源），可直接用 GitHub Pages 靜態托管。專案根目錄另附 `index.html`（僅以 meta refresh 轉往 `paladin.html`），因此 Pages 的**根網址即可進入遊戲**。

步驟：

1. 在 GitHub 建立一個**空**的 public repo（不要勾選自動產生 README）。
2. 在本機專案根目錄初始化並推送（`.gitignore` 已排除 `node_modules/`、`dist/`、`.saves/`）：

   ```bash
   git init -b main
   git add .
   git commit -m "第一章《仙島求藥》完成，含網頁版單一 HTML"
   git remote add origin https://github.com/<你的帳號>/<repo>.git
   git push -u origin main
   ```

3. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main** / **(root)**，按 Save。
4. 稍等一至兩分鐘，網址即為：

   ```
   https://<你的帳號>.github.io/<repo>/
   ```

   （`index.html` 會自動轉往 `paladin.html`；也可直接開 `.../<repo>/paladin.html`。）

注意事項：

- Pages 對 **public repo 免費**；private repo 需 GitHub Pro 才能使用 Pages。
- 之後每次更新遊戲，記得先 `npm run build:web` 重新產生 `paladin.html`，再 commit／push，Pages 才會更新。
- 存檔存於瀏覽器 `localStorage`，各裝置各自保存、不會同步。

## 操作方式

- 以「數字 + Enter」選擇選項；一般訊息按 Enter 繼續；**任何選單按 Esc 取消**（戰鬥中選擇攻擊目標或武功對象時，按 Esc 可退回上一層）。
- 開場劇情播完後進入主選單：**探索 / 移動 / 仙術 / 道具 / 隊伍狀態 / 存檔 / 測試模式 / 離開遊戲**。
  - **移動**：前往相鄰場景（選單上方顯示現在地點）。
  - **探索**：與場景中的人物、物件互動；**找對對象才會推進劇情**，寶物取走後即不再出現；遇店鋪（鐵匠鋪／木匠鋪／藥鋪）互動則開啟買賣選單，遇床榻則可投宿休息（回滿生命與真氣）。
  - **仙術 / 道具**：戰鬥外「仙術」清單會列出**全隊每人**習得的仙術及其效果描述，惟**僅補血仙術（`kind: heal`）可於戰鬥外施展**（其餘以灰色文字顯示、不可選）；施展時先選施術者與仙術，再選對象（全體治療則作用於全隊）。「道具」於戰鬥外恢復生命、真氣；道具清單亦列出持有的裝備與材料（裝備請於「隊伍狀態」穿戴）；**寶物（嬸嬸的包袱、手卷）可於「道具」開啟／使用**。
  - **隊伍狀態**：查看屬性與裝備，可更換武器／防具／頭部／足部／飾品（穿上、卸下即時增減屬性）；各部位僅列出該角色依原作可穿戴的裝備。
- 戰鬥中選擇「攻擊 / 武功 / 物品 / 逃跑」；**每回合先為全體隊員下達指令，再依身法順序統一結算**（我方與敵方交錯出手），非「一人選完接著行動」。**戰鬥過程逐段顯示、每段間隔 0.5 秒**（誰對誰造成多少傷害等），一回合結束後**按 Enter 才會進入下一回合**。
- 戰鬥中的「物品」列出藥品類（恢復生命／真氣、復活）與暗器（投擲單體、造成固定傷害），裝備與材料不列入；選單會標示各道具的效果描述；生命／真氣已滿時不會浪費道具；暗器於戰鬥外不可使用。

## 架構：Data + Config + Constant → Model → System / Information

- **Constant / Config**（`src/config/`）：不改邏輯即可調整的數值，如經驗曲線、成長率、爆擊率、存檔位置。
- **Model**（`src/models/types.ts`）：所有實體與資料結構的型別定義。
- **Data**（`src/data/`）：角色、武功、物品、敵人、劇情、場景等純資料。
- **System**（`src/systems/`）：戰鬥、升級、劇情、探索、物品等規則運算。
- **Information / UI**（`src/ui/` 與 `src/engine/`）：僅負責呈現與流程驅動；遊戲流程集中於 `game.ts`，存讀檔獨立於 `save.ts`。

新增內容時，原則上只需在 `data/` 補資料、必要時在 `config/` 調數值，盡量不動 `systems/`。

## 開發規範

每個階段完成後，固定執行：

1. **文檔維護**：更新本 README 的進度、結構與藍圖狀態（連結一律使用相對路徑）。
2. **單元測試**：於 `tests/` 補齊或調整對應測試，執行 `npm test` 確保通過。
3. **忠實度查核**：涉及原著設定的內容（招式歸屬、傳功地點、劇情順序）須先查證再落筆，不得憑印象硬掰；參考來源見「原著考據來源」一節。
