# 遊戲特色

> 上層索引見 [README](../README.md)；操作方式見 [gameplay.md](gameplay.md)。

- **回合制戰鬥**：攻擊 / 武功 / 物品 / 逃跑，身法決定出手順序，含會心一擊與隨機掉落。
- **升級成長**：經驗、等級、屬性自動成長，並隨等級習得新武功（learnset）。
- **武學系統**：李逍遙（御劍術、天師符法、萬劍訣 Lv13、天劍 Lv23、逍遙神劍、劍神、酒神、山神、雷神、氣療術、凝神歸元、冰心訣、天罡戰氣、真元護體、醉仙望月步、仙風雲體術、元靈歸心術、飛龍探雲手、靈葫咒、金蟬脫殼）與趙靈兒（五系咒法、觀音咒、淨衣咒、金剛咒、回夢、還魂咒、五氣朝元、三昧真火、武神…）依原作補齊；林月如（凝神歸元、氣劍指、一陽指、銅錢鏢、七訣劍氣、元靈歸心術、乾坤一擲、斬龍訣；Lv7 一陽指、Lv10 銅錢鏢、Lv14 七訣劍氣、Lv17 元靈歸心術、Lv18 乾坤一擲、Lv22 斬龍訣）亦依原作補齊。御劍術由酒劍仙劇情傳授、氣療術為自帶。
- **戰鬥機制**：除攻擊／治療外，支援**異常狀態**（中毒、昏睡、定身、瘋魔、咒封）、**增益**（攻擊／防禦／身法）、**復活**、**解咒**、**偷竊**與**脫逃**；中毒每回合扣血、昏睡／定身無法行動、瘋魔不分敵我、咒封禁用仙術，身受擊會驚醒。
- **擋格彩蛋**：敵方普通攻擊隊友時，李逍遙會挺身替**女角**擋下這一擊（唯獨不替林月如），林月如則只替李逍遙擋格；擋格成功時由擋格者代受半數傷害。此為玩家間流傳的戲說、非原作明載，因頗合人物性格而實作。
- **劇情引擎**：節點式劇情、對話演出、抉擇分歧、戰鬥觸發、獎勵發放、劇情傳授技能。
- **場景探索**：以「移動／探索」在場景間走動；找對人物對話或物件互動才會推進劇情（點選式 ADV）。
- **當前目標**：狀態列依主線旗標顯示下一步該做什麼（例如「到渡口市集，替嬸嬸買幾斤新鮮的蝦」），全章完成後顯示收尾提示。
- **隱藏寶物**：依原著攻略在各場景布置可調查的寶物（皮帽、木鞋、梅花鏢、蠱卵、蓮蓬等），取走後即不再出現。
- **夥伴參戰**：趙靈兒自客棧獲救起加入隊伍、林月如自林家後山加入隊伍（等級比照李逍遙），入隊時各自自帶裝備——趙靈兒仙女劍（武術+8／防禦+5）、布袍（防禦+3）、青絲巾（防禦+2）、草鞋（防禦+1）；林月如林家寶劍（武術 +12）、披風（防禦 +2）、草鞋（防禦 +1）。三人皆可於戰鬥與「隊伍狀態」操作。**靈兒在隊時，仙靈島岩徑的綠葉小妖／綠葉妖精會自動退避**（見 [faithfulness.md](faithfulness.md)）。
- **裝備系統**：武器／防具／頭部／足部／飾品五部位，於「隊伍狀態」換裝；裝備即時加成屬性，卸下即還原。各裝備依原作的「裝備角色」設有對象限制（`Item.equipBy`，如繡花鞋／髮飾／玉鐲限女角、仙女劍限趙靈兒、生鏽鐵劍限李逍遙），換裝清單僅列出該角色能穿戴的品項。
- **商店買賣**：盛漁村渡口市集（鐵匠鋪曾大伯、木匠鋪林木匠、洪大夫藥鋪）與蘇州城內（回春堂藥鋪、蘇州鐵鋪、蘇州布莊）可買賣兵器、防具與藥品；售價依原作，出售比照當鋪以原價 75% 收購。
- **客棧投宿**：於客棧的床榻休息可回滿全隊生命與真氣；餘杭客棧因是自己的家，於李逍遙房休息免費，他處客棧（悅來客棧、林家東廂房）則需付投宿費（`restCost`）。
- **探索練功**：在十里坡、仙靈島岩徑、隱龍窟等野外「四下探索」，隨機遇上**遇敵／寶箱／空手**，可無限練功兼尋寶（**不做迷宮**）。十里坡在仙靈島歸來前封閉，詳見 [faithfulness.md](faithfulness.md)。
- **存讀檔**：純 JSON 存檔，資料結構向下相容於後續階段。
