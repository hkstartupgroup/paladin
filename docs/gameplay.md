# 遊戲進行與操作

> 上層索引見 [README](../README.md)；遊戲特色見 [features.md](features.md)。

## 操作方式

- 以「數字 + Enter」選擇選項；一般訊息按 Enter 繼續；**任何選單按 Esc 取消**（戰鬥中選擇攻擊目標或武功對象時，按 Esc 可退回上一層）。
- 開場劇情播完後進入主選單：**探索 / 移動 / 仙術 / 道具 / 隊伍狀態 / 存檔 / 測試模式 / 離開遊戲**。
  - **移動**：前往相鄰場景（選單上方顯示現在地點）。
  - **探索**：與場景中的人物、物件互動；**找對對象才會推進劇情**，寶物取走後即不再出現；遇店鋪（鐵匠鋪／木匠鋪／藥鋪）互動則開啟買賣選單，遇床榻則可投宿休息（回滿生命與真氣）。
  - **仙術 / 道具**：戰鬥外「仙術」清單會列出**全隊每人**習得的仙術及其效果描述，惟**僅補血仙術（`kind: heal`）可於戰鬥外施展**（其餘以灰色文字顯示、不可選）；施展時先選施術者與仙術，再選對象（全體治療則作用於全隊）。「道具」於戰鬥外恢復生命、真氣；道具清單亦列出持有的裝備與材料（裝備請於「隊伍狀態」穿戴）；**寶物（嬸嬸的包袱、手卷）可於「道具」開啟／使用**。
  - **隊伍狀態**：查看屬性與裝備，可更換武器／防具／頭部／足部／飾品（穿上、卸下即時增減屬性）；各部位僅列出該角色依原作可穿戴的裝備。
- 戰鬥中選擇「攻擊 / 武功 / 物品 / 逃跑」；**每回合先為全體隊員下達指令，再依身法順序統一結算**（我方與敵方交錯出手），非「一人選完接著行動」。**戰鬥過程逐段顯示、每段間隔 0.5 秒**（誰對誰造成多少傷害等），一回合結束後**按 Enter 才會進入下一回合**。
- 戰鬥中的「物品」列出藥品類（恢復生命／真氣、復活）與暗器（投擲單體、造成固定傷害），裝備與材料不列入；選單會標示各道具的效果描述；生命／真氣已滿時不會浪費道具；暗器於戰鬥外不可使用。

## 測試模式與場景直跳（Debug 用）

- **測試模式**：開啟後主選單標題旁會顯示當前 scene id，方便核對劇情推進。
  - 遊戲中開啟：於主選單選擇「測試模式：開／關」即可隨時切換。
  - 啟動時開啟：`npm start -- --test` 或 `PALADIN_TEST=1 npm start`。
- **直跳場景**：傳入 scene id 可略過標題畫面，直接以新遊戲狀態進入該場景。
  - `npm start inn-hall`、`npm run dev inn-hall`
  - 未知的 scene id 會列出所有可用場景。
  - 可用場景 id 見 [src/data/scenes/index.ts](../src/data/scenes/index.ts) 的 `SCENES`。
