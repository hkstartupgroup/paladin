# 原著考據來源

> 上層索引見 [README](../README.md)；改編取捨見 [faithfulness.md](faithfulness.md)。

開發時凡涉及原著設定，一律以下列資料為準，並於必要時交叉查證：

- [仙劍奇俠傳 DOS/95/98 版圖文攻略（青衫）](https://chiuinan.github.io/game/game/intro/ch/c11/pal/pal/pal.htm)：**主要依據**。盛漁村序幕、十里坡、仙靈島等流程與敵人清單。
- [新仙劍奇俠傳 完全攻略（青衫）](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/index.htm)：**故事流程／戰鬥／道具／裝備／仙術的主要依據**。含[遊戲攻略](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/palgame.htm)（故事流程）、[裝備列表](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/item.htm)、[仙術列表](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/spell.htm)、[敵人列表](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/enemy.htm)、[蠱物煉化](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/mix.htm)／[靈葫煉化](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/linhu.htm)，以及屬性、升級成長範圍、毒性與[攻擊傷害公式](https://chiuinan.github.io/game/game/intro/ch/c11/palgame/index.htm)等戰鬥規則。
- [仙劍奇俠傳系列劇情對話資料（雪團整理）](https://paldialogue.sarakale.top/zh-tw/)：**劇情對話原文**資料庫（主線／支線／NPC 對話）。台詞一律以此為準；原始檔案庫：[SaraKale/paldialogue](https://github.com/SaraKale/paldialogue)，新仙劍主線位於 `zh-tw/Paltoc-tc/newpal/newpal_MainStory/`（`newpal_MainStory_01.htm` 為第一章）。網站為 SPA，取原文請直接讀原始庫。
- [新仙劍奇俠傳完美攻略（cnblogs）](https://www.cnblogs.com/cxeye/p/4003355.html)：**場景互動資料的主要依據**。依地點詳細記錄主線、支線，以及主要人物／NPC／物件的互動內容，並標註各地寶箱與隱藏寶物（如逍遙房花架皮帽、書櫥木鞋等），供 `src/data/scenes/` 的 `interactables` 對照（其「夢境·羅剎洞」序章暫不採用）。
- [仙劍奇俠傳 完全攻略本（DOS 版，archive.org）](https://archive.org/download/ddsc-game-manuals/DDSC-J-00265-%E9%81%8A%E6%88%B2%E6%94%BB%E7%95%A5%EF%BC%9A%E4%BB%99%E5%8A%8D%E5%A5%87%E4%BF%A0%E5%82%B3.pdf)：餘杭鎮開場流程與十里坡山神廟等第一手情節。
- [李逍遙 — RekoWiki](https://newkomica-kari.fandom.com/zh-tw/wiki/%E6%9D%8E%E9%80%8D%E9%81%99)：角色經歷與仙術一覽（御劍術、氣療術、萬劍訣、天劍、酒神、雷神等）。
- [仙劍奇俠傳（初代）— 萌娘百科](https://mzh.moegirl.tw/%E4%BB%99%E5%89%91%E5%A5%87%E4%BE%A0%E4%BC%A0%E4%B8%80)：主線劇情；「十里坡山神廟醉漢傳授御劍術」即出自此處。
- [仙劍奇俠傳系列 — 萌娘百科](https://mzh.moegirl.tw/%E4%BB%99%E5%89%91%E5%A5%87%E4%BE%A0%E4%BC%A0)：系列沿革與各版本差異。
